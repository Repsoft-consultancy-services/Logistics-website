# Kranthi Packing Industries – Wooden Pallet Website

A Next.js website for **Kranthi Packing Industries**, wooden pallets and packaging in Hyderabad.

## Features

- **Hero** – Business name and call-to-action
- **About** – Company intro and location (Bowrampet, Hyderabad)
- **Services** – Wooden pallets, packaging solutions, bulk supply
- **Contact** – Full address, phone (+91 86861 84331), email (kranthikumar.t10@gmail.com)
- **Footer** – Address and contact repeated for easy access
- Responsive layout and mobile menu
- Wood-themed styling with Tailwind CSS

## Tech stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Google Fonts (DM Serif Display, Source Sans 3)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
